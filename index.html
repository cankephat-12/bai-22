Bài 22: CSS cơ bản- Inline, internal, and external CSS tutorial for web development

1. Tổng quan CSS

* CSS (cascading Style Sheets):

- Là một ngôn ngữ được sử dụng để tìm và định dạng lại các phần tử được tạo ra bởi ngôn ngữ đánh dấu (HTML)
- Nếu HTML đóng vai trò định dạng các phần tử trên website như việc tạo ra các đoạn văn bản, các tiêu đề...
Thì CSS sẽ giúp ta có thể thêm style vào các phần tử HTML đó như đổi bố cục, màu sắc trang, đổi màu chữ, font chữ...

2. Vị trí đặt CSS

<tag style="css"></tag> = Inline (CSS nội tuyến)
<style>CSS</style> = Internal (CSS nội bộ)
<link href="style.css"/>= ExternalCSS bên ngoài

A. Inline (CSS nội tuyến) là cách viết nã ngay trong phần tử cơ bản HTML

Nhược điểm:

  • 1. Khó thay đổi, mỗi lần thay đổi phải thay đổi một cách riêng lẻ.
  • 2. Không tái sử dụng được.
  • 3. Khó quản lý.
  • 4. Khó tách biệt cấu trúc.
<!DOCTYPE html>
<html lang="vi">
    <head>
        <meta charset="UTF-8" />
        <meta name="viewport" content="width=device-width, initial-scale=1.0" />
        <title>cankephat</title>
    </head>
    <body>
    <h1 style="color: red">Hello, World!</h1>
    <!-- 1. style = thuộc tính (name of Attribute) 
         2. "color: red" = giá trị (Value foe Attribute)
            2.1: color = property
            2.2: red = value-->
    </body>
    </html>

Ví dụ:

Hôm nay Phát học CSS

<h1 style="color: red">Hôm nay Phát học CSS</h1>

B. Internal (CSS nội bộ) là cách viết mã CSS trong cặp thẻ style (đặt trong khối head) 


    <style> 
    h1{ 
        color: blue; 
        font-style: italic; 
    }
    </style>

Ưu điểm:

  • Code tách biệt với phần tử, có thể áp dụng với toàn bộ trang.

Nhược điểm:

  • Vẫn khó quản lý khi dự án lớn, quá nhiều mã CSS sẽ làm tệp HTML trở nên cồng kềnh.

C. External (CSS bên ngoài): trong trường hợp muốn áp dụng cho toàn bộ các file
HTML nằm trên trang web, tránh việc phải copy css ra tất cả các file

* Là cách viết mã CSS thành 1 tệp .css quản lý riêng.

* Cần khai báo trong HTML để linh đến tệp CSS

<link rel="stylesheet" href="style.css" />

* rel="stylesheet" thông báo cho trình duyệt, tải tệp CSS được chỉ định và áp dụng các định dạng kiểu trong trong tệp đó cho trang web hiện tại

D. Độ ưu tiên - Inline, internal, and external CSS

* Độ ưu tiên giữa 3 cách đặt CSS (từ Cao đến thấp)

- Inline(CSS nội tuyến) => Internal (CSS nội bộ) - External (CSS bên ngoài)

* Internal (CSS nội bộ) External (Css bên ngoài): Trong code HTMl chính, phần khai báo của cách nào ở sau thì sẽ ghi đè lên cách trước đó.
